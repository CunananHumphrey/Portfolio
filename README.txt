HUMPHREY C. CUNANAN — LITERARY PORTFOLIO
========================================

FILES
- index.html: complete responsive portfolio website
- assets/music/: place an optional MP3 file here

PUBLISH ON GITHUB PAGES
1. Create a new GitHub repository (Public is easiest for a class portfolio).
2. Upload index.html and the assets folder to the repository's ROOT.
3. Open repository Settings > Pages.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. Wait for GitHub to publish the site. Your page URL will appear in the Pages section.

CUSTOMIZE LAB TASKS
- Open index.html in a text editor such as VS Code or Notepad.
- Find the section marked "Laboratory tasks".
- Change each card's title, description, category, and href link.
- For each View work link, replace href="#" with your actual file or project URL.
- You can also use the on-page "Edit cards" and "+ Add a card" controls for quick edits.
  Note: on-page edits are temporary until you also update index.html and upload it to GitHub.

ADD OPTIONAL MUSIC
1. Put an MP3 file inside assets/music/.
2. Rename it to your-music.mp3, OR update the <source src="..."> path in index.html.
3. Commit and push the updated files to GitHub.
4. Visitors must press Play; browsers do not allow autoplay with sound by default.

CONTACT
Replace your-email@example.com in index.html with the email address you want to display.

The page uses Google Fonts when internet access is available; it has fallback fonts if not.
