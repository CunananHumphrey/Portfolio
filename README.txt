HUMPHREY C. CUNANAN — LITERARY PORTFOLIO
========================================

This GitHub Pages-ready portfolio includes:
- Lab Task 1: 2D Array (assets/documents/LabTask1-2DArray.pdf)
- Lab Task 2: 3D Array (assets/documents/LabTask2-3DArray.pdf)
- Responsive vintage literature design, animations, hover effects, and optional music controls.

PUBLISH ON GITHUB PAGES
1. Extract this ZIP.
2. Upload index.html and the entire assets folder to the ROOT of your GitHub repository.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder / (root), then Save.
6. Wait for GitHub Pages to publish your site.

CUSTOMIZE
- Open index.html in VS Code or another text editor.
- Find the Laboratory tasks section to edit task titles and descriptions.
- The View documentation links already point to the included PDFs.
- The on-page Edit cards and + Add a card controls are quick visual helpers. Changes made in the browser are temporary; edit index.html to make them permanent on GitHub.

OPTIONAL MUSIC
Place your MP3 in assets/music/ and name it your-music.mp3, or update the audio source path in index.html. Visitors press Play to start it.
